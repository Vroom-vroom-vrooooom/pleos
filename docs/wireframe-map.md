## 원본과 의도적으로 구분한 것

- 내비게이션 분할 화면, Gleo AI, 공조·시스템 바는 차곡 앱 코드의 소유 범위가 아닙니다.
- 원본의 ‘폰에 알림을 보냈어요’, ‘연결 가능’ 등의 문구는 현재 구현이 성공한 것으로 오해하지 않도록 미연결 안내로 바꿨습니다.
- 사진, 장소, 경로는 예시이며 실제 권한이나 API 지원을 보증하지 않습니다.
- 복잡한 애니메이션·지도·외부 로그인보다 단계 이동과 데이터 경계를 먼저 정의했습니다.

## 차량 UI 개정

2026-11-12 웹 목업 기준: C01은 출발 인사, C02는 중앙 구체 라디오, C03은 대화형 경유지 승인, C04는 장소를 한 곳씩 추천, C05는 하루를 마무리하는 질문입니다. 일정과 기록 목록은 요청 시 오른쪽에 펼칩니다. 로컬 데모 셸의 왼쪽 예시 내비는 차량 화면 전환 중 유지하며 실제 Pleos 내비 연결은 포함하지 않습니다.
